## What this is
PostgreSQL schema: users, system_prompts, vision_profiles, mcp_credentials + partial unique index enforcing one active profile per user. Alembic-managed.

## Current state
Migration `3ab5256d84ee` applied to dev DB; 10 schema tests pass against real Postgres (pgserver instance) including partial-index, RESTRICT, CASCADE, one-MCP-credential uniqueness.

## Key decisions made while building this
- **Alembic env.py auto-converts asyncpg→pg8000 URLs** (added Phase 14/15): migrations run against settings.DATABASE_URL without manual URL swapping; pg8000 is a runtime dep for prod images.
- pgserver keeps the server alive only while its parent Python process lives → scripts/dev.py starts pgserver + uvicorn in one process; conftest holds it for the whole pytest session.
- Migrations excluded from ruff strict checks (autogenerated files) except env.py.
